# ClipboardUltra

ClipboardUltra is a macOS menu bar clipboard manager designed to make copied content easier to find, organize, and reuse. The app stores clipboard history, offers search and category filters, supports pinned items, and can be opened instantly with a keyboard shortcut.

# Features
- Menu bar app for quick access.
- Clipboard history stored locally.
- Search bar to find previous copied content.
- Category filters such as text, numbers, URLs, emails, images, and pinned items.
- Image preview for copied images.
- Dark mode toggle.
- Global shortcut to open the app quickly.
- Simple settings panel.

# Security
- ClipboardUltra can be configured with safety-focused behaviors to better protect sensitive copied data.
- Auto-clear clipboard history after a chosen delay, useful for reducing the time sensitive content stays available.
- Optional exclusion of copied secrets coming from password managers such as NordPass, Bitwarden, 1Password, and KeePass.
- Local-first history model for users who want clipboard access to stay on-device.
- Better handling of copied images with preview support without needing to paste them first.

# Installation

Option 1 — Install from a .dmg
- Download the latest .dmg release from the GitHub Releases page.
- Open the .dmg file.
- Drag ClipboardUltra.app into the Applications folder.
- Open Applications and launch **ClipboardUltra**.

PS: If macOS shows a warning because the app was downloaded from the internet, open System Settings > Privacy & Security and allow the app to run.
Grant requested permissions if features such as shortcuts or automation require them (not mandatory).
